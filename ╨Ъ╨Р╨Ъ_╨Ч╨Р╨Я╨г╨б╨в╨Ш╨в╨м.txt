МИНИМАЛЬНЫЙ WPF CRUD — ООО «Обувь»

1. Откройте wpf-shoes.slnx в Visual Studio (Windows).
2. Проверьте подключение LocalDB в App.config: (localdb)\MSSQLLocalDB, база shoes_db.
   База данных НЕ входит в архив. Используется ваша локальная shoes_db.
3. Запустите проект (F5).
4. Гость/клиент — просмотр каталога.
5. Менеджер — поиск по названию, фильтр по категории, сортировка щелчком по заголовку,
   отдельная вкладка заказов (просмотр).
6. Администратор — две вкладки (товары/заказы). Редактируйте ячейки прямо в таблице.
   Для добавления используйте пустую строку внизу, затем нажмите «Сохранить».
   Для удаления выберите строку и нажмите «Удалить выбранное».

ВАЖНО:
- productId и orderId по вашей EDMX модели не являются IDENTITY: задавайте уникальные ID вручную.
- Для новых товаров обязательно заполняйте существующие ID поставщика, производителя, категории.
- Для новых заказов заполняйте корректные addressId, userId, обе даты и другие обязательные поля.
- Данные сохраняются только по кнопке «Сохранить».
- SQL Server может запретить удаление при наличии связанных записей.
- При ошибке сохранения закройте окно администратора и откройте заново,
  чтобы сбросить несохраненные изменения EF.
- Пароли сравниваются как открытый текст только ради совместимости с учебной БД.
  В реальном проекте нужны хеши паролей.
- Для фильтрации используется обычный список в памяти; небольшая учебная БД — ОК.
- На Linux здесь нельзя собрать Windows .NET Framework 4.8/WPF проект;
  сборку и запуск проверьте в вашей Visual Studio на Windows.
